<objective>
Wire the LL brand tokens through Shopify's settings system so a merchant can edit colors and typography in the theme editor and see updates live across all sections via CSS custom properties.

Purpose: SCAFFOLD-02 requires that brand token values flow `settings_schema.json (color picker) → settings_data.json (default) → settings.ll_color_* (Liquid) → :root --ll-color-* (CSS) → var(--ll-color-*) (consumed by sections)`. The whole chain must be wired in this plan because partial wiring (e.g., schema without theme.liquid injection) silently fails — values exist but never reach CSS.

Output:
- 11 `--ll-color-*` CSS custom properties + 1 `--ll-font-body` defined in inline `<style>` in `layout/theme.liquid` `<head>`
- Brand Tokens settings group in `config/settings_schema.json` (per Claude's discretion in CONTEXT.md — separate group from Dawn's own color_scheme_group, which we leave intact per RESEARCH.md Open Question §2)
- Theme Store-compatible defaults in `config/settings_data.json` (accent ships as neutral #1a1a2e per D-05, NOT Loris Lots purple #5b3df2)
- `shopify theme check` reports zero new errors after this plan
</objective>
